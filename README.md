## Cài Đặt & Chạy Dự Án

```bash
# 1. Cai dat dependencies
npm install

# 2. Chay moi truong Development 
npm run dev

# 3. Kiem tra build TypeScript & Bundle production
npm run build
```

## Quy Chuẩn Git Commit 

Định dạng chuẩn:
`<type>(<scope>): <noi dung khong dau>`

- `feat`: Them tinh nang moi
- `fix`: Sua loi
- `style`: Thay doi giao dien, css/scss ma khong anh huong logic
- `refactor`: Tai cau truc code
- `chore`: Cap nhat cau hinh, thu vien, khoi tao project
